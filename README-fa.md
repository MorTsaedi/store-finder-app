# راهنمای مغازه‌ها — Store Finder

اپلیکیشن وب موبایل‌محور برای پیدا کردن مغازه‌ها و خدمات محلی در تهران. ساخته شده با Next.js، نقشه Leaflet، و طراحی الهام‌گرفته از Yandex Maps.

## امکانات

### نقشه و کشف مغازه‌ها
- **نقشه تعاملی Leaflet** با آیکون‌های دسته‌بندی و نشانگرهای رنگی باز/بسته
- **نشانگرهای امتیاز** روی نقشه که میانگین امتیاز مشتریان را نمایش می‌دهند
- **پنل جستجو** با نتایج فوری، فیلتر دسته‌بندی و مرتب‌سازی بر اساس فاصله یا امتیاز
- **فیلتر باز/بسته** برای پیدا کردن مغازه‌های فعال در حال حاضر
- **پنل پایین** با جزئیات مغازه و امکان بستن با کشیدن به پایین

### جزئیات مغازه
- **تصویر اصلی** با وضعیت باز/بسته و برچسب دسته‌بندی
- **اطلاعات تماس** — تلفن (تماس مستقیم)، آدرس، فاصله
- **ساعات کاری** — برنامه هفتگی کامل با برجسته‌سازی امروز
- **درباره ما** — توضیحات کسب‌وکار
- **امتیازات و نظرات** — ستاره‌ها و سیستم نظردهی با ذخیره‌سازی محلی
- **شبکه‌های اجتماعی** — تلگرام، اینستاگرام، واتساپ با دکمه‌های رنگی
- **مسیریابی** — دسترسی مستقیم به Google Maps

### نوبت‌دهی آنلاین
- **رزرو نوبت** برای آرایشگاه‌ها، کلینیک‌ها، سالن‌های زیبایی و سایر خدمات
- **تقویم جلالی** با انتخابگر تاریخ فارسی و پیمایش ماه
- **grid ساعات موجود** تولید شده از ساعات کاری و مدت زمان هر نوبت
- **وضعیت نوبت‌ها** — ساعات رزرو شده و گذشته غیرفعال هستند
- **تأیید نوبت** با انیمیشن موفقیت
- **خلاصه رزرو** — تاریخ، ساعت و اطلاعات مشتری قبل از ثبت

### طراحی موبایل‌محور
- **رابط کاربری الهام‌گرفته از Yandex Maps** — کارت‌های تمیز، گوشه‌های گرد، سایه‌های ملایم
- **بهینه‌سازی iOS** — جلوگیری از جابجایی صفحه کلید مجازی
- **بازخورد لمسی** — انیمیشن لمس روی تمام عناصر تعاملی
- **حاشیه ایمنی** برای دستگاه‌های با بریدگی صفحه‌نمایش
- **چیدمان راست‌به‌چپ** با فونت وزیرمتن فارسی
- **بستن با کشیدن** روی تمام پنل‌های پایین (جزئیات مغازه + نظرات)

### داده‌های نمونه
- **۱۰۴ مغازه** در ۱۰ دسته‌بندی:
  - مواد غذایی و نانوایی
  - داروخانه
  - پوشاک و مد
  - خدمات خودرو
  - الکترونیک
  - آرایشگاه و زیبایی (قابل رزرو)
  - کتاب و لوازم تحریر
  - رستوران و کافه
  - کلینیک و عینک‌سازی (قابل رزرو)
  - ورزش و تناسب اندام
- ساعات کاری، شبکه‌های اجتماعی و توضیحات برای هر مغازه

## فناوری‌های استفاده شده

| لایه | فناوری |
|------|--------|
| فریمورک | Next.js 16 (App Router, Turbopack) |
| رابط کاربری | React 19, Tailwind CSS 4 |
| نقشه | Leaflet با تایل‌های OpenStreetMap |
| پایگاه داده | SQLite (better-sqlite3) |
| مدیریت وضعیت | React useState/useEffect |
| فونت | وزیرمتن (Google Fonts) |
| تقویم | jalaali-js (تاریخ جلالی) |

## شروع کار

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# باز کردن در مرورگر
open http://localhost:3000
```

پایگاه داده SQLite (`demo.db`) در اولین اجرا به صورت خودکار ساخته و با ۱۰۴ مغازه پر می‌شود.

## ساختار پروژه

```
src/
├── app/
│   ├── api/
│   │   ├── appointments/route.ts    # CRUD نوبت‌دهی
│   │   ├── categories/route.ts      # لیست دسته‌بندی‌ها
│   │   └── shops/
│   │       ├── [id]/
│   │       │   ├── route.ts         # جزئیات مغازه + ساعات کاری
│   │       │   └── route.ts         # ساعات موجود نوبت
│   │       └── route.ts             # لیست مغازه‌ها با فاصله
│   ├── globals.css                  # Taillet + بازنویسی‌های Leaflet
│   ├── layout.tsx                   # لایوت ریشه با فونت‌ها
│   └── page.tsx                     # اپ اصلی (کامپوننت کلاینت)
├── components/
│   └── MapView.tsx                  # نقشه Leaflet فقط کلاینت
└── lib/
    └── db.ts                        # اسکیمای SQLite + داده نمونه
```

## APIها

| متد | آدرس | توضیحات |
|-----|------|---------|
| GET | `/api/categories` | لیست تمام دسته‌بندی‌ها |
| GET | `/api/shops?lat=&lng=&radius=&category=&q=&open=` | جستجوی مغازه‌ها |
| GET | `/api/shops/[id]` | جزئیات مغازه با ساعات کاری |
| GET | `/api/shops/[id]/slots?date=YYYY-MM-DD` | ساعات موجود نوبت |
| POST | `/api/appointments` | ثبت نوبت جدید |
| GET | `/api/appointments?phone=` | لیست نوبت‌ها با شماره تلفن |
